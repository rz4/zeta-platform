# The Zeta name

The code in this repository is open (see LICENSING.md). The NAME is
held to a standard, because the name is a promise: every machine
called Zeta runs every gated cart identically — not compatibly,
identically — and proves it.

## You may call it Zeta when

- it is an unmodified build of this repository's law and silicon; or
- it is an implementation that passes the complete conformance suite
  for its declared generation (`CART_GEN`) bit-for-bit — every cart,
  every claim, every golden — with no test waived.

## Otherwise

Fork freely, build freely, sell freely — under another name. A
modified machine, an implementation that fails or skips any part of
the suite, or a work-in-progress port must not present itself as a
Zeta, a Zeta-N, or a name confusingly similar. "Based on Zeta" or
"Zeta-derived" as a factual statement is fine.

## Why this is the enforcement arm of the constitution

FAMILY.md's compatibility theorem is a gate, and a gate binds only
those who run it. A license cannot force a fork to stay conformant;
a name policy can make conformance and the name travel together. The
promise "your cart runs identically, forever, provably" is only worth
making if nothing wearing the name can quietly break it.
